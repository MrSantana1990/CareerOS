# Security

Não versione `.env`, cookies, tokens, perfis de navegador, currículos ou screenshots. Troque todas as senhas do `.env` antes de iniciar. Serviços são publicados somente em `127.0.0.1`. Autoaplicação é desativada por padrão; CAPTCHA e MFA sempre exigem intervenção humana.

Reporte vulnerabilidades diretamente ao mantenedor, sem incluir dados pessoais nos logs ou issues.
