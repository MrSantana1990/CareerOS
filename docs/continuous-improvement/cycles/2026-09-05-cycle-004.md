## Auditoria de rotas já existentes no código (achado real)

`detect_email_application()` (`email_discovery.py`) já detecta com segurança um e-mail real de candidatura no texto da vaga (nunca inventa, exige instrução explícita, ignora no-reply). `create_application_email_draft()` (`google_career.py`) já cria um rascunho real no Gmail com currículo anexado. **Mas nada conecta os dois automaticamente** — não existe geração de mensagem a partir do perfil/currículo/vaga, e o endpoint `/google/application-draft` exige que o chamador forneça `recipient`/`subject`/`body` manualmente. Essa é a lacuna real que impede o canal de e-mail de funcionar ponta a ponta hoje — mas como nenhuma vaga real com e-mail detectável surgiu neste ciclo (0/41 + 0 no histórico completo), não havia candidato real para validar essa conexão. Documentado para quando surgir uma vaga real com esse canal.
